Accept a payment

Create the charge

Send a POST request to /v2/charges, with the fields form-encoded, not as JSON:

Parameter Description
amount Amount as a decimal string, for example "10.50".
currency Optional. Defaults to usd.
card_token Token from AIKloop.js. 
curl https://api.aikloop.example/v2/charges?api_key=YOUR_KEY \
  -d amount=10.50 -d card_token=tok_123

If something goes wrong

If a request times out, just send it again.
