Knowledge Loop demo

Same docs, two versions

AIKloop Payments is a fictional API. Its docs exist in two versions. Both look fine to a human. The difference is what an AI coding agent can get out of them.

Before Stale docs The same pages, but the docs were never updated after v3: old endpoints, and nothing says they're out of date. The API reference is drawn by JavaScript. No Markdown, no llms.txt. After After a Knowledge Loop pass The same pages, updated for v3, with a changelog of what changed. The API reference is generated when the site is built. Every page also in Markdown, and an llms.txt file that tells agents which version is current and what not to use.

Built with Hugo. Both versions use the same layout and table of contents, and both API references come from the same API spec. The difference is the content and what an agent can read. Domains end in .example, a reserved ending that can never point to a real site.
