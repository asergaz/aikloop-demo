What the agent did with each version

The seven prompts were coding tasks: the Claude Code agent had to write a Python script, which was then tested against a mock of the AIKloop API. The agent ran with Opus 5.5: the larger, more expensive model. And with Haiku 5.5: the cheaper model that many developers pick to keep costs down, especially for automated work.

Each prompt got {{ $first.repeats }} attempts per version, in a fresh session, and every Python script was tested.
