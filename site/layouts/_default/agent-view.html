What the agents did with each version

Claude Code wrote code for seven everyday tasks, such as charging a card, refunding half a payment or verifying a webhook. Each task was asked {{ $first.repeats }} times per version, every time in a new session that could only read that version's docs. Then each answer's code ran against a mock of the API. Two models took part: Opus 5.5, and the smaller and cheaper Haiku 5.5, the kind teams often use for automated work. Run on {{ (time.AsTime $first.date).Format "2 January 2006" }}.

What the agent sees

An AI agent doesn't see the page you see. It reads the text behind it. On the left, what an agent gets from the "before" page: the HTML with the tags removed, without running scripts. On the right, the Markdown version of the "after" page, which agents can ask for. Its HTML page says the same, and that's what most agents in the tests read.
